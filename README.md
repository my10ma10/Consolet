# Описание проекта
Консольный мессенджер с клиент-серверной архитектурой на C++20.

Позволяет создавать чаты и обмениваться сообщениями с другими клиентами. 

**Проект создан в учебных целях и не предназначен для использования в качестве мессенджера.**

## Цели проекта
- Изучение работы API сокетов и основ сетевого взаимодействия
- Практика использования многопоточности (одновременный приём и отправка сообщений)
- Организация структуры проекта с использованием паттерной (клиент–сервер, множественные интерфейсы, команды)
- Использование RAII, smart pointers, STL
- Практика с Gitlab CI
- Написание тестов с покрытием
- Использование БД

# Функциональность
Приложение позволяет авторизоваться и выбрать CLI (пользовательский или командный) 

## Сервер
- Подъем на указанном порту
- Прием и обработка подключений клиентов
- Закрытие сессий
- Рассылка сообщение целевым клиентам

## Клиент
- Подключение к серверу
- Авторизация по логину
- Выбор интерфейса
- Отправка сообщения
- Получение сообщения отдельным процессом

## Интерфейсы
### Пользовательский 
Удобен для среднестатистического пользователя
Пример:
```bash
1. Написать сообщение
2. Открыть чат
3. Вывести список чатов
4. Выход
```

### Командный
Позволяет отправлять сообщения, используя команды:
- /msg `username` `message` - отправить сообщение `message` пользователю `username`
- /list - вывод списка активных чатов
- /chat `username` - отобразить чат с пользователем `username`
- /exit - выйти из аккаунта
- /quit - выйти из приложения

# Сборка и запуск

```bash
cmake -S . -B build
cmake --build build
```

Для работы программы запустить два процесса:
```bash
./build/src/server/server
./build/src/client/client
```

Запуск тестов:
```bash
./build/tests/tests 
```
